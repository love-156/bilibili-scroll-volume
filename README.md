# Bilibili 滚轮音量控制

一个用于哔哩哔哩（B站）视频页面的油猴脚本，适用于在没有开启全屏/网页全屏时，通过鼠标滚轮精确调节视频音量。

## 功能特性

### 核心功能
- **滚轮调节音量**：按住触发键/鼠标在指定区域 + 鼠标滚轮调节音量
- **音量增益**：支持超过100%音量增益（最高200%）
- **视觉反馈**：实时音量指示器显示当前音量

### 触发方式
| 方式 | 说明 |
|------|------|
| 按键触发 | 按住指定按键 + 滚轮 |
| 区域触发 | 鼠标在指定区域内无需按键即可触发 |
| 全屏直接触发 | 全屏模式下无需按键，直接滚轮调节 |

### 设置选项
- **触发按键**：可自定义（默认v）
- **音量步进**：1-100% 可调（默认5%）
- **全屏模式**：禁用 / 启用 / 直接触发
- **鼠标要求**：可选必须鼠标在视频上
- **区域触发**：可编辑触发区域

### 其他特性
- 支持拖拽移动设置面板
- 设置自动保存到本地
- 全屏模式独立音量指示器
- 支持区域可视化编辑

## 安装

1. 安装油猴（Tampermonkey）浏览器扩展
2. 安装此脚本：`bilibili-scroll-volume.user.js`
3. 访问 B站视频页面即可使用

## 使用方法

| 操作 | 说明 |
|------|------|
| 调节音量 | 按住触发键 + 鼠标滚轮 |
| 打开设置 | 油猴菜单 → 🎵 滚轮音量设置 |
| 修改触发键 | 设置面板点击触发按键按钮，按下新键 |
| 编辑触发区域 | 开启区域触发后点击"编辑区域" |

## 快捷键

| 按键 | 功能 |
|------|------|
| v（默认） | 触发音量调节 |
| Esc | 取消按键监听 |

## 技术实现

- **音量控制**：使用 Web Audio API 实现超过100%音量增益
- **状态管理**：通过 `data-screen` 属性检测全屏状态
- **持久化**：使用 GM_getValue/GM_setValue 保存设置
